## 읽는 법과 한계

1. **교육청 자료의 과정별 교습비는 교습소만 채워져 있습니다.** 표본의 학원 252곳은 모두 교습비가 비어 있었고, 교습소 365곳 중 230곳이 교습비를 공개했습니다. 교습소는 강사 1명이 운영하는 소규모 시설이라 큰 학원보다 대체로 쌉니다. 그래서 위 "실제"는 교습소 시세에 가깝습니다.
2. 예시 데이터는 학원 가격대(대형 학원, 서울 비중이 큼, 강남·목동 프리미엄 반영)를 본떠 만들어서, 교과 과목이 실제 교습소보다 30~120% 높게 잡혀 있습니다. 예능(피아노·미술·제2외국어)은 실제와 비슷하고, 바이올린은 오히려 낮습니다.
3. 표본은 학원 이름에 과목 키워드가 들어간 곳 위주라 무작위 표본이 아닙니다. 지역별 정확한 비교는 인증키로 지역 전체를 받아 다시 계산해야 합니다:

```bash
NEIS_KEY=발급키 npm run neis:compare          # 대표 지역 14곳 → docs/neis-comparison.md
```
